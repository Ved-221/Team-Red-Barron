# Project Instructions — Team Red Baron Website

## Stitch Project Configuration
- **Stitch Project ID:** `projects/4397091508073276184`

## Core Rules & Requirements

1. **Mobile Responsiveness:**
   - All pages, layouts, and components must be fully responsive for mobile, tablet, and desktop viewports. Keep mobile ergonomics and scaling top-of-mind.

2. **Admin Panel Requirements:**
   - Provide an admin panel UI/routes for updating member photos and descriptions, adding new team photos, adding vehicles, and managing competitions.

3. **Dummy Data & Assets:**
   - Use dummy content, placeholder images, and mock data for initial development. Real images and text copy will be swapped in later.

4. **External React Components & Aesthetic Mapping:**
   - External components provided by the user (e.g., React Bits, Aceternity UI, Magic UI) must be mapped and styled to strictly match the project's design system in `DESIGN (3).md`:
     - **Theme:** Mach-Red Kinetic (Pitch Black `#000000`, Primary Red `#DE1615`, Orange `#FF6534`, Glassmorphism `#252E39` at 60% opacity with blur).
     - **Typography:** Sora (Display/Headlines), Inter (Body), JetBrains Mono (Technical labels/stats).
     - **Styling Feel:** High-octane, elite offroad/F1 motorsport aesthetic, translucent cards, subtle outer glows.

5. **Homepage Integration:**
   - The user will provide a custom intro animation to be integrated prior to / on the homepage.

6. **Official Logo Asset:**
   - Always use `image (2).png` (saved as `public/logo.png`) as the official logo across all components and pages. The old logo file is removed.
